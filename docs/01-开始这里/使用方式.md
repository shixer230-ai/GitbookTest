# 使用方式（学生版：不用 Git）

这份手册暂时**不要求学生学习 Git 或使用命令行**。大家只需要在浏览器里使用 GitBook 网页即可；仓库、同步和技术维护由班级管理员负责。

## 阅读内容

1. 打开老师或管理员发出的 GitBook 站点链接。
2. 从目录选择正在学习的语言或主题。
3. 阅读“前置知识”和示例后，亲自在自己的电脑上运行代码。
4. 遇到问题，记下报错提示、使用的工具/版本和已经尝试过的方法，再向同学或老师提问。

## 提交自己的笔记或修改

只有被管理员邀请为编辑者的同学可以修改内容。收到邀请后：

1. 登录 GitBook，打开班级知识库。
2. 在要补充的页面点击编辑，或在合适的分类下新建页面。
3. 按“适合谁、前置知识、示例、常见错误、我的收获”的顺序填写内容。
4. 点击 **Preview（预览）** 检查标题、代码块和链接是否正常。
5. 在 **Changes（修改）** 中提交本次修改，并写一句清楚的说明，例如“补充 Python 列表练习”。
6. 等待老师或内容管理员审核、合并；合并后内容会显示在公开站点。

> 找不到编辑按钮、无法新建页面或没有收到邀请时，请联系班级管理员。普通访问者可以阅读，但不能直接修改。

## 写笔记的小约定

- 一篇文章只讲一个小主题，标题要让新同学一眼看懂。
- 示例代码请自己运行一次，再贴到页面中。
- 报错和踩坑很有价值：写出原因与解决办法，能帮到下一位同学。
- 参考网上资料时，请附上链接，并用自己的话说明学到了什么。
- 不要写入账号、密码、密钥、个人隐私或未经允许传播的课程资料。

## 推荐学习节奏

每周选择一个小主题：看 30 分钟、动手 60 分钟、整理 15 分钟、互相点评 15 分钟。

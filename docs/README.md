# 班级编程共学手册

欢迎来到我们的共同学习空间！这里收集适合新手的编程笔记、示例代码、工具指南和项目复盘。

## 从这里开始

- 新同学请先看 [使用方式](01-欢迎!/使用方式.md) 和 [贡献说明](01-欢迎!/贡献说明.md)。
- 选择一门正在学习的语言，按目录阅读或补充内容。
- 每篇笔记尽量说明：**适用场景、前置知识、示例、常见错误、下一步**。
